# Experiment 02 — Recurrent persona / voice motifs

## Goal

Search for recurrent glyph/block families disproportionately associated with selected human-figure contexts.

## Sequence

1. Define target folios without assigning semantic meaning.
2. Separate labels, circular writing, and running text.
3. Extract n-grams / STA blocks.
4. Build matched controls by hand, section, locus type and token count.
5. Rank motifs by enrichment and effect size.
6. Inspect near-variants of top motifs.
7. Only after replication, consider phonetic/prosodic interpretations.

## First target

f72r2 / Gemini should be recorded separately from adjacent zodiac panels rather than treating the entire foldout as one context.
