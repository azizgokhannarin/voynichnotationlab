# Experiment 05 — Notation evolution

## First probe

`B4` / EVA `g`.

RF1b first bound-order occurrence: f3r.1.

## Design

A three-point anecdotal comparison is insufficient. Target at least:

- 10–20 early samples;
- 10–20 middle samples;
- 10–20 late samples;
- equivalent control samples of glyphs already common on f1r.

Prefer comparisons within the same proposed scribal hand.

## Outcomes

**Supports maturation:** B4 variance decreases or the gesture becomes systematically more economical while controls remain comparatively stable.

**Weakens maturation:** B4 is already stable at first appearance and remains so.

**Confounded:** differences align mainly with hand, section, substrate, or transcription variation.
