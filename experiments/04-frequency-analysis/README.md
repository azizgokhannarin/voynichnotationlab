# Experiment 04 — Conditional frequency analysis

## Goal

Move beyond global frequency counts.

## Required distributions

For glyph/block g:

- f(g)
- f(g | token position)
- f(g | line position)
- f(g | paragraph position)
- f(g | folio/section)
- f(g | scribal hand)
- f(g | visual context)
- f(g_i, g_j) transitions

## High-priority candidate

The EVA-y-like terminal glyph is a useful probe because it has a strong token-final preference in standard transcriptions.

Do not assign it a phonetic value initially. Test competing roles:

- ordinary sound
- suffix
- syllable ending
- prosodic marker
- structural terminator
