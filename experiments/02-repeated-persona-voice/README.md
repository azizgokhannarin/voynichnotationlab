# Experiment 02 — Repeated persona / voice motifs

## Goal

Find textual motifs unusually associated with recurring human-figure contexts.

## Procedure

1. Define target folios/regions before inspecting motif frequencies.
2. Extract tokens and n-gram/glyph-block candidates.
3. Build matched control sets.
4. Compute enrichment ratios and confidence intervals.
5. Cluster near variants by edit distance and glyph-shape family.
6. Repeat with section and scribal-hand controls.

## Do not assume

- that the motif is a word;
- that a figure represents a real historical person;
- that naked figures were drawn from direct observation;
- that enrichment implies a name or spoken phrase.

## Interesting outcome

A motif family that remains strongly enriched after section/hand/label controls.
