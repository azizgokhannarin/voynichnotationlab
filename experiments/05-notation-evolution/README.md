# Experiment 05 — Notation evolution

## Goal

Test whether newly appearing glyphs/blocks show handwriting maturation.

## Candidate design

For each candidate unit absent from f1r/f1v:

- first 10 occurrences
- middle 10 occurrences
- late 10 occurrences

Within the same proposed scribal hand where possible.

## Shape measurements

- normalized height/width
- slant
- curvature
- loop closure
- stroke economy proxy
- baseline offset
- attachment to neighbors
- within-window variance

## Control

Repeat the same measurements for a common glyph already present at the beginning.

## Supporting pattern

candidate variance decreases materially while control variance remains approximately stable.

## Alternative explanations

- different scribal hand
- different pen/nib
- writing speed
- parchment quality
- section-specific style
- folio order not matching production order
