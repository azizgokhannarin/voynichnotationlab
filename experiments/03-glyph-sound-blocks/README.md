# Experiment 03 — Glyph / sound-block segmentation

## Goal

Test whether recurring multi-glyph structures behave more coherently as units than individual EVA characters.

## Candidate unit types

- single glyph
- pair
- triplet
- ligature-like visual form
- prefix-like block
- suffix-like block
- positional operator

## Tests

- mutual information
- conditional entropy
- boundary preference
- recurrence stability
- substitution equivalence
- minimum-description-length segmentation

## Rule

Use neutral unit IDs (e.g. U001, U002) before assigning any sound value.
