# Experiment 01 — f1r / f1v micro-analysis

## Goal

Determine whether the first two manuscript faces contain evidence of a stable pre-existing notation system or signs of local experimentation / calibration.

## Questions

1. What glyph inventory appears on f1r and f1v?
2. Which recurring blocks appear?
3. Which glyphs prefer token initial/medial/final positions?
4. How do paragraph openings and endings differ?
5. Which glyph/block types first appear only after f1v?
6. Are the f1r red marks structurally associated with textual changes?
7. Does f1v visual left/right or upper/lower structure correlate with textual structure?

## Deliverables

- glyph inventory
- block inventory
- positional table
- paragraph comparison
- first-occurrence candidate list
- observation log with screenshots/citations
