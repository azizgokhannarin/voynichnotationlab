# External test protocol — visual mnemonic notation vs structured pseudo-writing

## Purpose

Test H20 without another unrestricted language search. The experiment must distinguish meaningful
visual mnemonic reuse from local motor-copy pseudo-writing.

## Required resources

- high-resolution Voynich folio images with stable folio/line coordinates;
- fourteenth–fifteenth-century Latin-script manuscript images in Latin and major European
  vernaculars;
- diplomatic abbreviation, shorthand, numeral and marginal-note samples;
- palaeographers or manuscript specialists for blinded annotation;
- optional computer-vision expertise in stroke/gesture similarity, not OCR translation.

## Experiment A — blind human perception

Prepare matched, anonymous crops containing:

- normal Voynich text;
- horizontally mirrored Voynich controls;
- line/stroke-order-disrupted Voynich controls;
- genuine medieval Latin-script samples;
- visually matched pseudo-writing controls.

Observers record Western-manuscript resemblance, perceived reading direction, recurring word-shape
families and any perceived letter sequence without being asked to find Latin.

Advance only if normal Voynich reliably exceeds mirrored/disrupted controls for directional
initial/terminal rhythm and observers agree on graphic families beyond chance. Agreement on vague
“text-likeness” alone is insufficient.

## Experiment B — local-copy versus distant-semantic recurrence

Represent word images as stroke/gesture graphs while preserving uncertainty. For every word image,
compare its nearest visual relative among:

1. the previous 1–5 tokens;
2. the rest of the same line/page;
3. distant folios with independently coded matching illustration motifs;
4. page/section/hand/length/line-position-matched nulls.

Local-only advantage plus line-width optimisation supports structured pseudo-writing. Held-out
distant motif advantage after all controls supports meaningful mnemonic notation.

## Experiment C — external source-manuscript challenge

Before inspecting Voynich correspondences, nominate a historically attested manuscript family or
source tradition from illustration/layout evidence. Freeze source pages, motif correspondences,
expected repeated concepts or passage structure, allowed visual transformations and at least one
unexamined Voynich folio prediction.

No claim advances without correct held-out prediction. Retrospective resemblance is exploration.

## Kill rules

- Do not add new languages, source books, transformations or visual metrics after held-out results.
- If only local copying transfers, classify H20 as structured pseudo-writing rather than meaningful
  mnemonic notation and stop semantic-source searching.
- If no image-grounded visual family survives adjudication, stop H20.
- Never infer diagnosis, identity or intent from visual similarity.
- Keep final-test pages sealed until a source or motif model predicts them directionally.
