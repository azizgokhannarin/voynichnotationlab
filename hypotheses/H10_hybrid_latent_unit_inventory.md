# H10 — Voynich uses a hybrid latent-unit inventory

## Hypothesis

The script need not have one uniform unit size.

Different visible structures may behave as:

- atomic signs;
- stable multi-glyph blocks;
- graphic compounds;
- modifier + base constructions;
- productive endings or onset frames.

## Motivation

Current independent observations:

- `qo` is an exceptionally constrained initial block;
- `da` is strongly onset-associated;
- `dy` is strongly terminal-associated;
- gallows form substitution families;
- gallows decomposition is contextually parsimonious;
- full decomposition of every glyph does not improve held-out prediction globally.

The last result argues against the extreme model "every stroke is an independent
linguistic unit".

## Prediction

A hybrid segmentation should outperform both:

1. all-EVA-atomic;
2. all-strokes-decomposed

on page-held-out prediction/MDL.
