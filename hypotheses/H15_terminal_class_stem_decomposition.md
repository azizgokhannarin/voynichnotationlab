# H15 — Voynich tokens contain a reusable terminal-feature class

## Candidate terminal inventory

`n, m, y, r, l, s` (plus implicit Ø / no terminal).

## Hypothesis

Many surface token types can be represented more economically as:

    STEM + TERMINAL_FEATURE

The terminal may be morphological, phonographic, clitic-like, structural, or mixed.

## Evidence required

- substantial recurrent stem reuse;
- multiple terminal alternatives per stem;
- contextual coherence among variants;
- stable dependencies between terminal choice and functional/syntactic context.

## Falsification

Raw vocabulary collapse alone is insufficient. The hypothesis weakens if alternative endings
do not form coherent families or if equally arbitrary non-terminal glyph sets perform as well
on the independent structural tests.

## Status

Structurally supported as a terminal feature class; grammatical interpretation open.
