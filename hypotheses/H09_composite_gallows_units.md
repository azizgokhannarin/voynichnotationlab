# H09 — Gallows are composite graphic units with possible functional decomposition

## Hypothesis

The tall gallows glyphs are learned composite gestures assembled from a small set of
reusable graphic components.

At least some component differences may correspond to functional/phonographic contrasts.

## Evidence

- analytical stroke decomposition exists independently of this project;
- gallows members substitute within many otherwise stable token frames;
- pedestalled forms preserve a shared frame while varying the gallows member.

## Competing explanations

- multi-phoneme ligatures;
- syllabograms;
- modifier/operator constructions;
- purely graphic allographs.

## Falsification

If decomposed components have no predictive value beyond treating the whole glyph as an
atomic category, linguistic decomposition is weakened even if graphic decomposition is true.

## Status

Graphic compositionality: supported.
Linguistic/phonetic compositionality: open.


## v1.1 quantitative update

A whole-page-held-out prediction test does **not** show a global win for full stroke
decomposition: best atomic and analytical-stroke compression are effectively tied.

A gallows-specific factor model is more encouraging:

- the graphic 2x2 pairing is best/tied-best among possible pairings;
- it preserves nearly all contextual predictability with about half the classifier
  output coefficients;
- its two component axes correlate differently with position and Currier state.

**Updated status**

- graphic compositionality: supported
- functional compositionality: moderately supported
- phonetic compositionality: open
