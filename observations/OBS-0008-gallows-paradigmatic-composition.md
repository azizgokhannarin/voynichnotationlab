# OBS-0008 — Gallows form a substitutional/compositional paradigm

The four common EVA gallows (`k,t,p,f`) repeatedly occupy the same slots in high-frequency
token families.

Examples include:

- `okaiin / otaiin / opaiin / ofaiin`
- `qokaiin / qotaiin / qopaiin / qofaiin`
- `okal / otal / opal / ofal`
- `chckhy / chcthy / chcphy / chcfhy`

The published analytical alignment alphabet also decomposes gallows and pedestalled
gallows into smaller stroke components.

Interpretation: treating all EVA gallows as unrelated atomic "letters" is an unnecessarily
strong assumption.
