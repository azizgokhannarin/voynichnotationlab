# OBS-0014 — Residual terminal structure survives layout control

Using only non-line-final occurrences and a conditional permutation null preserving
Currier state plus broad previous/next context:

- observed I(STEM;TERMINAL): 1.3724 bits
- null mean: 0.0644
- z: 619.38
- empirical p: 0.001248

Stem terminal profiles also diverge from the global terminal distribution more strongly
than the same conditional null.

Thus Gate A's layout effect is real but does not explain the whole terminal system.
