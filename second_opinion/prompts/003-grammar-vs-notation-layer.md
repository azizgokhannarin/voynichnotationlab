# Blind second-opinion prompt 003 — grammar vs notation layer

A large unknown-script corpus has highly regular combinatorial token forms. Some short units
prefer left/right boundaries; many tokens share apparent stems with multiple terminal
variants; several short tokens have unusually similar following-context distributions.

Without assuming a particular language or decipherment, propose 3–5 high-value tests that
distinguish:

1. genuine natural-language morphology/syntax; from
2. a real underlying language plus a writer-specific phonographic/notational layer.

Prioritize tests with low false-positive risk, including how to distinguish grammatical
terminal variation from layout-conditioned notation and how to avoid overfitting in any
later constrained phonetic search.
