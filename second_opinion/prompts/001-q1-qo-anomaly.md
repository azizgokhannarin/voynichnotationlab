# Blind review prompt 001 — Q1 `qo` anomaly

You are reviewing a quantitative pattern in an undeciphered manuscript.

Do not assume that the symbols encode natural language, a cipher, music, or phonetics.

The same transcription system gives the following rate of one token-initial symbol block
(`qo`) per 100 tokens across four nested physical sheets of one quire:

    0.90 -> 6.53 -> 9.00 -> 10.46

Two immediately following quires, classified with the same text-state A and same proposed
hand 1, do not show the same monotonic pattern:

Quire 2:
    7.10 -> 11.37 -> 6.94 -> 11.76

Quire 3:
    7.94 -> 12.90 -> 11.21 -> 10.38

In Quire 1, the three herbal pages on the outermost physical sheet have `qo` rates
0.85%, 1.16%, 2.07%;
they rank unusually low among 95 comparable A/hand-1 herbal pages. A fourth page on the
same sheet has a different layout class and contains no `q`.

Questions:

1. Rank at least four plausible explanations for this pattern.
2. Which explanation requires the fewest assumptions?
3. What confounds could create the pattern without any evolution of the notation?
4. What single next experiment would best distinguish local notation development from
   content/grammar effects?
5. What evidence would make you reject the notation-development interpretation?

Do not attempt a decipherment or assign sound values.
