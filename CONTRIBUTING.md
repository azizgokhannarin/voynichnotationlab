# Contributing

Contributions are welcome, especially attempts to disprove current hypotheses.

## Requirements

- Clearly separate observation from interpretation.
- Cite the folio and data source.
- Provide code or enough detail to reproduce quantitative claims.
- Report negative results.
- Avoid presenting speculation about historical identity, gender, diagnosis, relationships, or motive as fact.
- Do not assign phonetic values solely from visual resemblance.

## Suggested issue prefixes

- `OBS:` manuscript observation
- `HYP:` new or revised hypothesis
- `EXP:` experiment proposal
- `DATA:` data/provenance issue
- `RESULT:` experimental result
- `REPRO:` reproduction attempt
