# Frozen structural representation v1

Frozen before the first constrained historical-language campaign.

## Working representation

- visible spaces: meaningful generative boundaries, not automatically modern word boundaries;
- QO: promoted block candidate;
- DA: promoted onset/block candidate;
- DY: rejected as indivisible;
- Y-final: productive terminal feature;
- terminal layer: primarily core/rime-conditioned phonographic class, plus smaller external
  grammatical modulation and layout/state realization;
- m: strong physical-line-final-conditioned realization/notational feature;
- residual terminal profile zones: L/R-like, N-like, Y-like;
- or/s/r: stable functional-paradigm candidate; semantic class unresolved;
- gallows k/t/p/f: atomic at token level with internal graphic/functional features.

## Search discipline

During historical-language campaign 1:

1. do not change segmentation to improve a candidate language;
2. learn mappings on training material only;
3. do not manually remap held-out pages;
4. penalize null, many-to-one, context-sensitive and silent mappings;
5. compare to matched null/gibberish corpora;
6. correct for testing multiple languages;
7. isolated word resemblance has zero evidential status by itself.
